# Physics-Simulator
Team Software Project from team IBAD. 4COM2006

### Mohammad Amiri

## Brief
This code is related to the frontend side of things using raylib. <br>

Features included: Connecting backend to frontend, updating real world values to raylib values, and modifying the backend so it works with raylib. <br>

Features NOT included: Menu/GUI buttons, and multi ball functionality. Both not being my responsiblity. <br>

Some other code that you may see here used to be raw OpenGL testing/foundation code before we decided to move to raylib.
